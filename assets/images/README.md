# Images

- `fire.png` (and its 2.0x, 3.0x and 4.0x versions): the fire emoji (U+1F525) from Google's
  [Noto Emoji](https://github.com/googlefonts/noto-emoji), whose images are under the Apache
  License 2.0 (`NotoEmoji-Apache-2.0.txt`). Drawn from its SVG at 32, 64, 96 and 128 px. The
  account page shows it beside the streak, the same on every device and offline, where a font's
  emoji would depend on the system.
